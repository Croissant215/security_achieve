### 해결한 검사 문제

모바일 목록 이동 직후 가로 넘침 검사가 간헐적으로 실패했지만 바로 이어진 요소 좌표 검사에서는 넘친 요소가 없었다. 스타일 적용 후 조건이 성립하는지 `wait_for_function`으로 확인하도록 수정했고 동일 회귀 검사가 통과했다. 화면 밖 iframe의 전체 페이지 캡처가 비어 보일 때는 iframe으로 스크롤하고 표시 여부를 검사한 뒤 별도 화면 캡처로 방어 원문을 확인했다.

no-ai-slop 문구 검토에서 동작·입력·관찰 결과, 초기화 범위, 신호 관찰의 한계를 유지했다. 기존 안내를 새 게시판 동선에 맞게 고쳤다.

## 검사 중 해결한 오류

스키마 변환 테스트에서 WinError 32가 발생했다. `with sqlite3.connect(...)`는 트랜잭션을 끝내지만 연결을 닫지 않아 Windows에서 임시 DB 삭제가 막혔다. 테스트를 `contextlib.closing(sqlite3.connect(...))`과 명시적 `commit()`으로 수정한 뒤 7개 검사가 모두 통과했다.

문구는 no-ai-slop의 eval.md에 따라 동작·삭제 범위·현재 구현 한계가 남아 있는지 확인했다. 새 게시판 문구 검토 항목은 통과했으며, 탐지 전용 항목과 별도 원고 반환 항목은 코드 편집에 해당하지 않는다.
